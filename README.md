# Архитектор — Захват клеток

Браузерная стратегическая игра на клетчатом поле: игроки по очереди проводят рёбра квадратов, замыкают клетки и захватывают как можно больше территории.

**Играть:** откройте `index.html` в браузере — сборка и сервер не нужны.

## Возможности

- Два режима: **два игрока** и **против ИИ**.
- Три карты: **Прямоугольник** (5×4 … 10×10), **Классический ромб** (81 клетка), **Произвольная фигура** (65–85 клеток).
- Три уровня сложности:
  - Лёгкий — пустое поле;
  - Средний — заранее нарисованные рёбра;
  - Сложный — рёбра, фигуры «Г»/«Z» и серые клетки.
- Серые клетки уже заняты, не приносят очков и не участвуют в подсчёте игровых клеток.
- Клик или тап по клетке с тремя сторонами дорисовывает четвёртую.
- Автозаполнение цепочки и ускоренные ходы ИИ.
- Шахматные часы в режиме двух игроков при чётном числе игровых клеток; при равном счёте побеждает тот, кто потратил меньше времени.
- Адаптация под мобильные устройства в ландшафтной ориентации.
- Без ластиков: контур и нарисованные рёбра неприкосновенны.

## Управление

- Клик/тап по ребру — провести ребро.
- Клик/тап по клетке с тремя сторонами — дорисовать недостающее ребро.
- «Выход» — вернуться в начало и сбросить партию.

## Структура

